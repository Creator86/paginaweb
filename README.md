# NexusFlow Production Site — Guía de Despliegue en GitHub Pages

Este paquete contiene tu sitio web estático 100% optimizado y listo para ser alojado **gratis en GitHub Pages**.

## Pasos para publicar gratis en 3 minutos:

1. **Crear Repositorio en GitHub**:
   - Entra en [github.com](https://github.com) e inicia sesión.
   - Crea un nuevo repositorio (por ejemplo: `mi-sitio-web` o `tu-usuario.github.io`).
   - Elige que sea **Público** (Public).

2. **Subir los Archivos**:
   - Descomprime este archivo ZIP en tu computadora.
   - Sube todos los archivos descomprimidos (incluyendo `index.html`, la carpeta `css/`, las carpetas de páginas y el archivo `.nojekyll`) a la rama principal (`main`) de tu repositorio.

3. **Activar GitHub Pages**:
   - En tu repositorio de GitHub, haz clic en **Settings** (Ajustes) > pestaña **Pages** (en el menú izquierdo).
   - En **Build and deployment > Source**, selecciona **Deploy from a branch**.
   - En **Branch**, selecciona **main** (o `master`) y la carpeta **/ (root)**, luego haz clic en **Save**.

4. **¡Listo!**
   - En 1 a 2 minutos, GitHub te proporcionará tu URL pública segura con HTTPS (ejemplo: `https://tu-usuario.github.io/mi-sitio-web/`).
