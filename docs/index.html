Preguntas Frecuentes sobre la Documentación

Respuestas a consultas técnicas comunes de la plataforma.

Is the core domain model tied to React or next.js?

No. As specified in Document 101, @website-factory/core is 100% pure TypeScript and has zero dependencies on React, DOM, or CSS.

Can I export sites to purely static HTML and CSS bundles?

Yes. The single rendering truth ensures that projects can be exported cleanly to standalone static bundles with zero server-side lock-in.

How do responsive variants work across breakpoints?

Responsive overrides cascade seamlessly from wide down to mobile. Components are not duplicated across breakpoints; only their props and token assignments adapt.
